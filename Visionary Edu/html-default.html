HTML Tutorial - Нүүр хуудас

Тавтай морил! Энэхүү HTML хичээл нь вэб хөгжүүлэлтийн үндсийг сурахад тань туслах зорилготой. HTML нь вэб хуудасны бүтцийг тодорхойлох стандарт тэмдэглэгээний хэл юм.

Зөвлөгөө

HTML-ийг сурах нь вэб хөгжүүлэлтийн эхний алхам бөгөөд CSS болон JavaScript-ийг сурахаас өмнө энэ хичээлийг сайтар эзэмших нь чухал юм.

Энэхүү хичээл нь HTML-ийн бүх үндсэн ойлголтуудыг дараах дарааллаар хамрах болно:

<!DOCTYPE html> <html> <head> <title>Миний анхны вэб хуудас</title> </head> <body> <h1>Сайн байна уу!</h1> <p>Энэ бол миний анхны вэб хуудас.</p> </body> </html>
Туршиж үзэх

HTML гэж юу вэ?

HTML (HyperText Markup Language) нь вэб хуудсуудыг бүтээхэд ашиглагддаг стандарт тэмдэглэгээний хэл юм. Энэ нь:

Жишээ:

HTML элементүүд нь таг (tag) ашиглан тодорхойлогддог:

<tagname>Агуулга...</tagname>

HTML элементүүд нь вэб хуудасны бүтцийг тодорхойлдог бөгөөд текст, зураг, холбоос, хүснэгт, жагсаалт гэх мэт агуулгыг харуулах боломжийг олгодог.

Анхааруулга

HTML нь вэб хуудасны бүтцийг тодорхойлдог боловч загвар, хэлбэрийг CSS, харин үйлдлийг JavaScript-ээр хийж болно.
